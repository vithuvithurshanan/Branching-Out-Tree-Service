# Photography credits

The tree-work photography currently on the site is **licensed stock, used as a
placeholder**. Replace it with Branching Out Tree Service's own job photos before or soon
after launch — real crew and job-site photos convert far better than stock, and they remove
the attribution obligation below entirely.

While these files are in use, the CC BY images must be credited. The site links to this
file from the footer ("Photo credits"), which satisfies the attribution requirement.

## Replacing these

Drop your own photos into `public/images/` using the same filenames — no code change is
needed. Once every CC BY file above is replaced, delete the footer "Photo credits" link in
`src/components/Chrome.jsx` and this file.
